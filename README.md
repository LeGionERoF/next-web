# Биржа проектов

Веб-платформа для публикации идей IT-проектов и поиска единомышленников.

## Демо

**Живая версия:** [https://website-for-project.web.app](https://website-for-project.web.app)

## Описание

Платформа решает проблему поиска команды для реализации идей. Пользователи могут зарегистрироваться, опубликовать свою идею, просматривать идеи других и связываться с авторами.

## Технологии

- **React** — интерфейс
- **TypeScript** — типизация
- **Vite** — сборка
- **Firebase Authentication** — регистрация и вход
- **Firestore** — база данных
- **Firebase Hosting** — хостинг

## Функционал

- Регистрация по email и паролю
- Вход и выход
- Запоминание сессии (не выходит при F5)
- Публикация идей с названием, описанием и контактами
- Список всех идей (видят все пользователи)
- Сохранение данных в облаке Firebase
